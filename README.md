# Repos and Reps Recommended Repositories

A curated list of tools and repositories I use and recommend trying.

## Recommended repositories

### [Handy](https://github.com/cjpais/Handy)

**Offline, system-wide speech-to-text.**

I'm running Handy on a 2017 Intel MacBook Pro with 16 GB RAM, using NVIDIA Parakeet V3 locally. That's fairly conservative hardware, but it has been more than enough to make dictation one of the quickest ways for me to get text into the laptop.

The bit I really like is that Handy works system-wide. I can hit a global hotkey, dictate, and drop the transcription straight into whatever I am already using — replying around YouTube, talking to ChatGPT, writing notes in Obsidian, or filling in something on a website. I do not need to change tools just because I have changed applications.

It is also completely local. The transcription model runs on the laptop, so the same setup keeps working when I am offline. That is particularly useful when I am travelling: on a train, in a hotel, or anywhere else where I do not want to depend on a good connection just to dictate some text.

If you do a lot of writing across different apps, this is one I would definitely try.

### [Obsidian](https://obsidian.md/)

**Local-first notes, planning and knowledge management.**

I use Obsidian for both my personal planning and my studies. The main appeal for me is that everything can live locally: I can keep my notes alongside the other files and media I need, work with the same system offline, and avoid making my day-to-day workflow depend on a web service.

It is also very agent-friendly. Because the underlying material is local and flexible, I can build automations and integrations around it with agents — either working directly with my Obsidian vault or connecting it to other systems. That makes it useful as more than a notes app; it can become a local knowledge base that I can adapt around whatever I am working on.

Official GitHub releases and community metadata: [obsidianmd/obsidian-releases](https://github.com/obsidianmd/obsidian-releases)

### [PaperSetGPT](https://github.com/reposandreps/PaperSetGPT)

**A calmer, more readable ChatGPT setup that goes beyond a theme.**

I built PaperSetGPT because I wanted ChatGPT to be easier to read and a little lighter to live in for long sessions, particularly on older hardware. It uses ChatGPT's native theme system for the colours, but then goes further with readability-focused fonts and text controls, a minimal Brave profile, and conservative rendering tweaks that reduce unnecessary work without trying to replace how ChatGPT itself functions.

It also includes an optional output-style layer for the responses themselves: progressive reading, clearer hierarchy, and less visual friction. That combination is what makes it useful to me — it is not just a colour theme, but a reproducible reading environment for ChatGPT that covers both the browser around it and the way information is presented inside it.
